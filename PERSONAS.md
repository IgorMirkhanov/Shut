## Как использовать

### В UI

1. Откройте http://localhost:3000
2. Заполните поле "ТЗ" как обычно
3. **Установите галочку** "🎭 Генерировать 10 вариантов от разных персон"
4. Нажмите "Сгенерировать"
5. Система создаст 10 вариантов постов
6. Используйте вкладки для переключения между персонами

### В коде

```typescript
import { writeAllPersonasCopy } from './src/core/pipeline.js';
import { PERSONAS, getPersonaPrompt } from './src/core/personas.js';

const brief = {
  topic: 'Как начать медитировать',
  audience: '25-40 лет',
  goal: 'Переход на курс',
  cta_mechanic: 'comment_keyword',
  cta_keyword: 'МЕДИТАЦИЯ',
  brand: { name: 'MindFlow', colors: ['#000', '#fff'] },
  slides: [
    { n: 1, intent: 'hook', idea: 'Медитация помогает' },
    { n: 2, intent: 'value', idea: '3 шага для начала' }
  ]
};

const results = await writeAllPersonasCopy(brief);

// results: PersonaCopyResult[] с 10 вариантами контента
results.forEach(r => {
  console.log(`${r.personaEmoji} ${r.personaName}:`, r.copy);
});
```

## Архитектура

### Файлы

- **src/core/personas.ts** - Определение всех 10 персон с их профилями
- **api/personas-copy.ts** - API endpoint для генерации 10 вариантов
- **src/core/llm.ts** - Функция `callJsonWithCustomPrompt()` для персонализированных промптов
- **src/core/pipeline.ts** - Функция `writeAllPersonasCopy()` для генерации
- **prompts/copywriter-persona.md** - Шаблон промпта для персонализации
- **public/index.html** - UI с поддержкой персон (чекбокс, табы, функции)

### Процесс

1. **Парсинг бриефа** - как обычно
2. **Генерация контента** - для каждой персоны:
   - Генерируется персональный system prompt
   - Вызывается `callJsonWithCustomPrompt()` с промптом персоны
   - Выполняется QA валидация (до 2 раундов)
   - Результат сохраняется с метаданными (id, name, emoji)
3. **Отображение в UI** - табы для переключения между персонами
4. **Редактирование** - можно отредактировать любой вариант
5. **Скачивание** - скачивание всех 10 вариантов

## Особенности

✨ **Каждый пост уникален**
- Не просто переформулировка, а разные углы, метафоры, примеры
- Каждая персона пишет в своем стиле

🎯 **Оптимизация для аудитории**
- Разные персоны будут резонировать с разными людьми
- A/B тестирование 10 вариантов

💾 **Сохранение в локальном хранилище**
- Проекты с 10 вариантами сохраняются
- Можно вернуться и отредактировать любой вариант

🔄 **Совместимость с существующей системой**
- Работает с существующим briefs, slides, intents
- Без галочки - работает как раньше

## Требования

- Node.js 18+
- GEMINI_API_KEY для реальной генерации
- Все остальное уже установлено

## Примечания

- Каждый вариант генерируется отдельно, поэтому процесс занимает время
- QA валидация применяется для каждого варианта независимо
- Rate limiting от Gemini API может ограничить количество одновременных генераций
- UI корректно работает с локальным хранилищем браузера
